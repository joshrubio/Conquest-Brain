# E000 — EJEMPLO ILUSTRATIVO (no se publica)

Carpeta de referencia para ver **cómo se rellenan** los archivos de un episodio. No es un episodio real y **no se produce ni se publica**.

Caso usado como vehículo: **la Burbuja de los Mares del Sur (South Sea Company, 1720)** — elegido porque es dominio público total, sin personas vivas, con abundante registro histórico. Sirve para mostrar el formato de las tres partes (narrativa → reflexión → para llevar) y la disciplina de fuentes.

- `01-brief.md` — brief completo de ejemplo.
- `05-script.md` — primeras secciones del guion con tags `[S..]` de ejemplo.
- `03-source-log.csv` — fuentes de ejemplo (obras reales; localización exacta marcada como *a completar*).

Los demás archivos de la carpeta plantilla se rellenarían igual siguiendo `templates/`.
