# 19 — Lessons (working log, not a rulebook)

A pattern-memory, not a growing rulebook. **Max ~15 lines.** If this file is
about to exceed that, the oldest non-repeating line gets cut before a new
one is added — this is scratch space, `episodes/_STATUS.md`'s notes column
and the KPI log (`brain/07`) are the durable record.

## The loop

1. **Write here** only at Stage 5 (fact-check), and only when a correction
   reveals a *recurring* gap — something that would likely happen again on
   the next script, not a one-off fact this episode got wrong. One line:
   `- <episode> · <the pattern> · <the fix>`.
2. **Read this file** (it's short) when starting Stage 3 (outline) or
   Stage 4 (script) — apply its lines the way you'd apply any other rule.
3. **Graduate, don't accumulate.** The moment a line's pattern shows up a
   **second time** (same issue, different episode) — stop logging it here.
   Instead: add one concise line to the actual canonical rule doc it
   belongs to (`brain/02`, `08`, `09`, `13`…, whichever governs it), update
   that doc's `INDEX.md` row if the summary changed, and **delete every
   line here about it**. A pattern seen twice is a rule, not a note.
4. If a line sits here for a while and never repeats, it was a one-off —
   safe to delete whenever the file needs room.
