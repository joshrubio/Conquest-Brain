# Filtro de temas / topics

> Nivel 1. Decide si un **área recurrente** puede formar parte del canal. Un tema aprobado habilita muchas ideas; un tema vetado las bloquea todas.

## Filtros eliminatorios (todos deben ser SÍ)

| # | Filtro | SÍ / NO |
|---|--------|---------|
| TE1 | El tema encaja con la tesis del canal: caso real + reflexión humana/psicológica + lección aplicable. | |
| TE2 | Existen **al menos 5–6 casos** dentro del tema con **registro público documentado** (no solo 1–2 famosos). | |
| TE3 | Ninguno de esos casos exige tocar a la comunidad hispanohablante de Rotterdam ni datos del negocio de membresía. | |
| TE4 | El tema se puede tratar **sin caer en un registro sensacionalista** por naturaleza (true crime morboso, escándalo por el escándalo). | |
| TE5 | El tema **no** solapa la marca/línea editorial del negocio de membresía ni de otro canal del equipo. | |

**Cualquier NO → tema vetado.**

## Puntuación (0–3 cada criterio; mínimo para aprobar: ≥ 11 / 18)

| # | Criterio | Puntos |
|---|----------|--------|
| TP1 | Profundidad del filón: ¿cuántos episodios sólidos salen? (3 = >12 casos) | |
| TP2 | Disponibilidad de fuentes Tier A/B a escala (no solo para el caso estrella) | |
| TP3 | Riqueza del ángulo psicológico/humano transversal al tema | |
| TP4 | Relevancia sostenida para los públicos del canal (emprendedores, soñadores, trabajadores, gente de Fe, inmigrantes…) | |
| TP5 | Diferenciación: ¿aporta algo que otros canales en español no cubren igual? | |
| TP6 | Riesgo legal/reputacional bajo de forma general (3 = bajo) | |
| | **Total** | **/18** |

## Decisión

- **≥ 11 y eliminatorios SÍ** → `aprobado`. Registrar en [themes.md](themes.md).
- **7–10** → `en estudio`: falta mapear casos o fuentes.
- **< 7** o algún eliminatorio NO → `vetado` (anotar motivo).

## Revisión

Revisar los temas aprobados cada ~5 episodios: ¿el filón sigue vivo?, ¿algún tema derivó a tono sensacionalista en la práctica?
