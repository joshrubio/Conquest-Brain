# Sistema de tracks e ideas

Dos niveles: **track** (permanente, por persona) → **idea** de video individual.

```
TRACK (fijo)
   ├─ T01 Historias Inspiradoras  · owner de ideación: Usuario 002
   └─ T02 Exploración             · owner de ideación: Usuario 001
        │
        └─ IDEA de video ──[hook-title + cross-check de material + rúbrica]──► aprobada
                                                                                  │
                                                                                  └─ carpeta E0XX
```

## Nivel 1 — Tracks

No hay rúbrica que apruebe tracks: son **dos, fijos**. Ver [tracks.md](tracks.md).
- **T01 Historias Inspiradoras** — biografías/trayectorias (personas, empresas, familias, productos, métodos). Usuario 002.
- **T02 Exploración** — todo lo demás (errores, fraudes, sectas, burbujas, inventores saboteados, migración histórica…). Usuario 001.

## Nivel 2 — Ideas

Cada idea, en la **fase de ideación**, necesita:
1. **Track** asignado.
2. **Hook-title** estilo Farid Dieck — [brain/13-hook-naming.md](../brain/13-hook-naming.md). *Sin hook fuerte, no hay audiencia.*
3. **Cross-check de contenido disponible** — [brain/12-available-material-protocol.md](../brain/12-available-material-protocol.md). Solo dominio público. *Sin material, no hay episodio.*
4. Pasar los **eliminatorios** + **puntuación** de [idea-rubric.md](idea-rubric.md).

Registro: [idea-pool.md](idea-pool.md).

## Flujo

1. Owner del track propone la idea con su hook-title.
2. Cross-check de material (Protocolo 1).
3. Rúbrica de idea (eliminatorios + /21).
4. ≥14 y todo en SÍ → `aprobada` → carpeta de episodio → Stage 1 (Brief).

Guion de todos los episodios: **Usuario 001**. Fact-check: automático — L1 + L2, sin firma humana ([brain/14-fact-check-protocol.md](../brain/14-fact-check-protocol.md)).
