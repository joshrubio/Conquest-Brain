# 03 — Brand Identity (placeholder)

**Status: not set.** Working name `SEGMENTO` everywhere. This file holds the brief and the constraints so the identity can be decided later without reopening the blueprint.

## Hard constraints on the brand

1. **Separate from the membership business.** Different name, different logo, different handles, different visual language. A viewer must not read this channel as the business's channel. No shared wordmark, no "by [business]" tag on-screen.
2. **Separate from any other team video channel.** No shared branding, playlists, or cross-posting that merges identities.
3. Name and identity must work for a **broad Spanish-speaking audience** — not tied to Rotterdam, the Netherlands, or a local scene.
4. Must not imply the channel covers private individuals or local community stories. It signals: history, real cases, human insight.

## Channel-type decision (open)

Undecided: **own new YouTube channel** vs. **recurring segment inside an existing team channel**.

- If **own channel:** `SEGMENTO` is the channel name + handle.
- If **segment:** `SEGMENTO` is a sub-brand — series name, dedicated playlist, consistent title prefix, distinct thumbnail system — inside a host channel whose identity does **not** belong to the membership business.
- Blueprint works either way. Lock this before the first publish.

## Naming brief (for when we choose)

Desired associations: real stories, evidence, the human behind the event, a lesson worth keeping. Avoid: "news", "true crime" sensational register, anything location-bound, anything that overlaps the business name.

Deliverable when we do the naming pass: 6–8 candidates, each with — meaning, YouTube handle availability, .com availability, IG/TikTok handle availability, trademark quick-check, one-line rejection risk.

## Visual direction (to define)

- Narrator framing standard (Carmen on camera): shot size, background, lighting note.
- Archival treatment: framing, grain/vignette, caption style for documents.
- Lower-third / source-citation caption style.
- Typography: one display + one text face.
- Color: restrained palette; must differ from the membership business palette.
- Thumbnail system: face vs. archival, text length cap, contrast rules.

## Assets location

`brand/assets/` — empty until identity is set. Then: logo (svg + png), fonts (licensed), thumbnail templates, lower-third templates, source-card template, channel banner, avatar.
